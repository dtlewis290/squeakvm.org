# squeakvm.org
This is a git mirror of the upstream squeakvm Subversion repository at http://squeakvm.org/svn/squeak/trunk.

Commits are expected to originate from the upstream SVN respository and are copied to git via git-svn.

Note that the version naming of compiled unix VMs is derived from the SNV version file, which currently requires use of Subversion in the local repository.
